# NCT NYANKO Web

냥코 베이스 스타일의 웹 편집기 시작 프로젝트입니다. 기존 NCT 봇에서 사용하던 BCSFE 편집 핵심을 웹 API로 연결하고, 모바일에서도 보기 편한 UI를 제공합니다.

## Termux
```bash
cd ~/nct_web
bash start.sh
```

브라우저에서 `http://127.0.0.1:5000`을 엽니다.

## 공개 서버
`NCT_HOST=0.0.0.0 PORT=5000 NCT_SECRET_KEY=긴랜덤문자열 python app.py` 형태로 실행할 수 있습니다. HTTPS/도메인/역방향 프록시는 서버 환경에 맞춰 별도로 구성해야 합니다.

## 적용된 핵심
- BCSFE 3.6.0 기반
- 세이브 이어하기 코드 + 인증번호로 불러오기
- 아이템/재화 편집 API
- 캐릭터 레벨/해금/진화 관련 API
- 보물 최고급 60,000,000% 고정
- 기존 네코치터(ネコチーター) 일괄편집 제거 로직 유지
- 세이브 업로드 API

PONOS 공식 제품이 아닌 비공식 커스텀 도구입니다.
